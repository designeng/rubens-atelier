Three weeks building a workshop where AI agents write the code

Denis Savenok · November 2026

Rubens didn't paint every canvas himself. His apprentices did most of the work, and the master walked the studio, corrected, and signed.

That's the idea behind rubens-atelier, an open-source "software factory." You hand it a GitHub issue. AI agents plan the change, write the code, review each other's work, pass CI and open a pull request. My job is the last step: look it over and merge.

Getting an agent to write code is the easy part now. Getting it to work reliably, safely and without burning money took most of the ~200 commits. Here's what I learned along the way.

Don't let the AI run the process

Left to decide its own next step, an agent wanders. So the process is fixed: plan, build, review, ship. The agent only reports how its step went, and the workflow decides what comes next. When an agent and a reviewer kept bouncing work back and forth forever, a simple visit limit fixed it: after a few rounds, a human steps in.

Parallel work collides

Five agents working at once means five pull requests stepping on each other. Before review, every branch now pulls in the latest main. If there's a conflict, the agent resolves it and the change goes back through review.

Cost creeps up quietly

Long AI sessions get expensive fast, because every request re-reads everything that came before. The fix was to hand agents short summaries of earlier steps instead of their whole history, and to give each one only the tools it actually needs. Every run now records what it cost, so nothing is a surprise.

Trust nothing by default

Agents run in a sandbox with no access to secrets. If the sandbox fails to start, the run stops instead of carrying on unprotected. Issues written by strangers can hide malicious instructions, so they wait for a human to approve them before any agent touches them.

Separate the roles for real

The planner can only read. The reviewer can't edit code at all. Otherwise "review" turns into "I wrote it, so I approve it."

Expect things to break

Workers crash and messages get lost. The system notices, picks up where it left off, and the agent continues its session instead of starting over.

The takeaway

The model is the simplest part. The real work is everything around it: a predictable process, isolation, visibility into cost, and clear points where a human makes the call.
