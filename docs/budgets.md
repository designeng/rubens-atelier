# Budgets

A project and any work item may have a `budget_usd` (greater than zero; `null` removes it). What was spent is the sum of `cost_usd` of the runs: of an item and all its descendants (so an epic's budget covers its stories), or of all the project's runs. Items, the board and `GET /projects` return it as `spent_usd`, and the board shows it on the cards, in the item panel and in the header. Before an agent run starts, the harness takes the tightest limit among the item, its parents and the project. If nothing is left, no agent starts: the step ends with the `budget` verdict and an `error` artifact (in `story.yaml` that goes to `next.error`, i.e. `needs_human`); raise the limit (`PATCH`, or the **Budget** field of the item or **Settings**) and retry. Otherwise the run's own `max_budget_usd` is `min(what is left, HARNESS_DEFAULT_MAX_BUDGET_USD)`. The limit is checked when a run starts, so agents running in parallel can overshoot it by up to their per-run caps.
